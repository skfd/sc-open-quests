# Prior art

- jmizv/sc-quest-stats (Codeberg, https://codeberg.org/jmizv/sc-quest-stats) — "which StreetComplete quests are not solved in your city"; quests as JSON with hand-written Overpass queries; results in a static QUESTS.md. No time series, no multi-city site.
- wielandb, "Some StreetComplete-Statistics" (OSM diary, 2022) — solved-quest counts for ~5,284 users from StreetComplete's per-user stats; by quest type and country, not city.
- piebro/openstreetmap-statistics — global edit/contributor counts per editor incl. StreetComplete.
