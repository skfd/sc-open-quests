The numbers

The counts are this project's own estimate of what a StreetComplete user would see with the app's default settings. They are made from a copy of OpenStreetMap that is a day or more old, with StreetComplete's quest code at one pinned version. What your app shows can differ, and a count can be wrong, late or missing.

Fetching the data yourself

The data files are plain JSON and you may read them from your own programs; the format is documented. Please be gentle with a free host:

  • the files change once a day, so fetch a file once a day and send conditional requests;
  • do not crawl every place file in a loop; ask for a bulk copy in an issue instead;
  • file names and fields can change with the site, without notice.

Traffic that puts the site at risk may be blocked.

Places and borders

Place names and boundaries come from OpenStreetMap and Overture Maps. Places are filed under the country whose rules StreetComplete applies there. The site takes no position on borders or on the status of any territory.
